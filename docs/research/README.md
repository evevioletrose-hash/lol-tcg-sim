## Established collection

Local recovery: 438 Wayback capture records, 318 distinct successful digests, 317 verified nonempty payloads, one inferred empty favicon. 161 Common Crawl rows (49/53 collections complete), including the two exact WARC fallbacks. No known nonempty indexed object missing. This is not proof of complete historical coverage. The full original game client remains missing.

Private game dossier: four original videos, 888 extracted screenshots, 13 original contact sheets, 41 annotated screen states and 19 closeups. Each screen has timestamps and exact original frame references. Visual sources are retained privately; the shared text and evidence indexes explain what they establish.

The original main branch was a historical simulator baseline; restoration is the active development line. The research integration is documentation only. All research statements may be revised in place when better evidence arrives, with uncertainty retained rather than papered over. No game balancing or runtime simulation results yet.
