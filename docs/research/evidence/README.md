# Evidence indexes

- [Digital card facts](digital-card-facts.json): 300 distinct historical digital card IDs (200 BB, 88 Item, 12 Place), 22 clubs, rank statistics and structured effects. No original art, verbatim effect descriptions, UI strings or executable code. Edition-local IDs: never import into printed catalogue automatically.
- [Rules fixtures](rules-fixtures.json): two visually observed digital combats, printed worked example and two printed policy fixtures. Not executed tests.
- [Original objects](original-objects.json): 229 original recovered responses, URLs, capture timestamps, SHA-256 and private relative paths. Not the final temporal inventory.
- [CDX original](cdx-original.json) and [expanded 2021–2024](cdx-2021-2024.json): original supplied indexes. The final 438-row index and Common Crawl WARC records are private and more recent. 

- [Legacy archive inventory](legacy-archive-inventory.json): exact Git blob fingerprints of every original tracked archaeology file, for retirement verification.

All large or third-party payloads (including the actual January game configuration), complete screenshot/atlas inventories, video hashes, final indexes and recovery scripts belong to the private vault. See [workspace](../workspace.md). The repository is a usable factual reference, not a complete copy of the original platform. The source game database digest is RM43E7CVBGHRIQHDKCHTS67Y5ZOYKXJY.

- [Tabletop gap leads](tabletop-gap-leads.json): all 89 baseline incomplete records, 64 digital ID candidates and 25 physical collector-checklist names; not printed verification.
- [Asset crosswalk](asset-crosswalk.json): nine digital art identities with both file sizes and other recovered asset groups, path-based associations only.
- [FIFA 2022 checklist](fifa-2022-checklist.json): twelve crossover identities, visually transcribed promotional Style/Groove pairs and numbering, two individually readable ranks; back content and other printed mechanics unverified.
